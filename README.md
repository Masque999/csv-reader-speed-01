A faster drop-in for make.fun's csv-reader 1.0.0: identical answers on every case, ~2x faster on the practice set.

## Run it

```sh
node main.ts
```

The harness runs `node main.ts` (Node 22). It reads every case from `MAKEFUN_INPUT_DIR` (default `/input`) and writes the answers to `MAKEFUN_OUTPUT_DIR` (default `/output`).
